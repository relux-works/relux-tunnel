# Add credential-free generated-project build validation

## Description
Add the local and pull-request validation surface for deterministic generation, every generated target, shared tests, relay target shells, native packaging seams, entitlement-file expectations, and legacy coexistence without requiring production signing credentials.

## Scope
In scope: pinned-tool bootstrap; deterministic generation drift checks; macOS host and provider Debug/Release builds with signing disabled; explicit verification that deferred iOS targets and schemes are absent from the macOS-only graph; ReluxTunnelCore and harness tests; relay target-shell and native-packaging checks; static entitlement and embedding inspection; legacy SwiftPM regression; local clean-checkout entry point; equivalent macOS pull-request workflow definition; privacy-safe artifact and log locations. Out of scope: generating or building deferred iOS targets, production certificates, physical Gate P0 repetition, Linux CI, TestFlight, notarization, DMG publication, full SBOM policy, packet feature tests, and SSH host conformance already owned by their tasks.

## Acceptance Criteria
1. One documented local entry point and equivalent macOS pull-request job definition run deterministic generation, every active macOS credential-free build, shared Swift Testing suites, relay smoke, native linkage checks, and legacy regression checks. 2. The gate fails on generator drift, missing or unexpected target/scheme, invalid embedding, entitlement-file mismatch, unpinned dependency input, disallowed linkage, accidental deferred-iOS activation, or legacy build regression. 3. Logs and artifacts identify source revision, tool versions, SDKs, deployment targets, and invoked schemes without exposing secrets. 4. Signing-required and deferred-iOS checks are explicitly reported as NOT RUN with reasons, never as passed. 5. The local validation completes from a clean checkout using documented prerequisites, and the checked-in PR workflow invokes the same entry point without duplicating policy.
