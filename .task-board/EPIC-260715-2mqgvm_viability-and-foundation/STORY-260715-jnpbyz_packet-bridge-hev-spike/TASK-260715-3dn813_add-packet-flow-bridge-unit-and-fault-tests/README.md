# Add PacketFlowBridge unit and fault-injection tests

## Description
Create deterministic Swift Testing coverage for the approved PacketFlowBridge contract using injected packet-flow, socket, readiness, descriptor-borrow, clock, logger, metric, scheduler, and lifecycle-barrier controls.

## Scope
In scope: IPv4 and IPv6 family words and payload-version agreement; empty, undersized, unknown-family, truncated, zero-length, and oversized datagrams; packet boundaries; count/time budgets; all requested/effective socket buffer gauges; normalized Darwin would-block behavior; ENOBUFS, EMSGSIZE, peer EOF, PacketFlow rejection, persistent errors, first-error races, cancellation at every startup stage, late callbacks, repeated lifecycle, and descriptor/task/registration accounting. Out of scope: real HEV behavior, physical-device throughput, SSH, routes, DNS, private APIs, arbitrary sleeps, and hard-coded final tuning values.

## Acceptance Criteria
1. Swift Testing covers forward and reverse IPv4/IPv6 bytes exactly and proves every malformed-frame rule, including that recvmsg length zero is a malformed datagram rather than EOF. 2. Fault injection proves EAGAIN and EWOULDBLOCK symbolic inputs normalize to the same truthful would-block reason, ENOBUFS is bounded loss, and EMSGSIZE, peer EOF, PacketFlow rejection, short datagram sends, and unclassified errors take their exact fatal transitions without retry or side storage. 3. Count and fake-monotonic-clock budgets count valid and invalid work, flush/yield at the specified boundary, preserve at most one current batch, and never depend on sleeps. 4. Cancellation at every startup/cleanup stage, first-error races, late packet-flow callbacks, and at least one hundred start/stop cycles return descriptors, tasks, readiness sources, continuations, and callback registrations to baseline while B closes only after consumer return. 5. Tests assert every required metric name, unit, endpoint-specific buffer value, monotonic/saturating counter, max datagram gauge, rate-limited privacy-safe log, and explicit prohibition seam.
