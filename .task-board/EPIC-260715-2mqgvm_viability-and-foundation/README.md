# M0 — Viability and foundation

## Description
Resolve Apple platform viability and prove the packet, memory, SSH, and project foundations that all product work depends on.

## Scope
Apple packet-tunnel intended-use evidence, Relux Works capabilities, multi-target project plan, public packet bridge spike, HEV constraints, and SSH-engine selection. No production feature work is accepted before its gates pass.

## Acceptance Criteria
Gate A0 is deferred off this epic's critical path under ADR-013 and stays required before App Store distribution and iOS submission, where it must have documented evidence; Gate P0 installs a packet-tunnel provider on the physical Apple-silicon Mac; the physical-iPhone row is a named deferred gap under ADR-024, never inferred from Mac results and never a pass; packet bridge/HEV and one SSH engine pass the M0 matrix; open decisions are recorded with reproducible results.
