# Implement the private SOCKS endpoint and bounded CONNECT parser

## Description
Implement the approved generation-private SOCKS service used only by the owned HEV instance. Preserve the accepted IPv4-loopback plus fresh RFC 1929 capability mechanism, replace the current SO_RCVTIMEO-only authentication behavior with one caller-injected monotonic accept-to-authentication absolute deadline, accept bounded sessions, parse CONNECT for IPv4, IPv6, and domain targets incrementally, and reject malformed or unsupported input safely.

## Scope
In scope: bind and teardown; private endpoint configuration injected into HEV; per-generation admission material; a monotonic timestamp captured at accept; remaining-budget enforcement across greeting reads, method reply, RFC 1929 reads, both credential comparisons, and authentication reply; pending-slot release; incremental CONNECT reads; fixed domain and frame caps; trailing early-payload handoff; reply encoding; unsupported method or command handling; cancellation; stale-generation rejection; aggregate parser/admission metrics; deterministic shared tests and iOS/macOS provider-sandbox validation. Out of scope: direct-tcpip open, byte pumping after successful CONNECT, public listener configuration, UDP ASSOCIATE, BIND, user credentials, DNS interception, destination logging, and changing the accepted endpoint mechanism.

## Acceptance Criteria
1. Only a client holding the current generation capability can complete negotiation; credentials are regenerated and released per runtime generation, and loopback or TCP peer metadata is never treated as process identity. 2. One caller-injected monotonic absolute deadline starts when a descriptor is accepted and spans every greeting and RFC 1929 read, method/authentication reply write, and both credential comparisons; partial progress, EINTR, readiness wakeups, or a slow reader never extends it, and expiry, cancellation, or stale generation closes before adapter handoff and releases the pending slot exactly once. 3. The parser accepts valid IPv4, IPv6, and strict ASCII or IDNA domain CONNECT requests across arbitrary fragmentation, preserves the destination exactly within the contract bounds, and hands a coalesced early-payload suffix into one reserved bounded pump buffer. 4. Unsupported versions, methods, commands, reserved fields, address types, zero ports, invalid or oversized domains, invalid leading bytes, truncation, or deadline expiry produce the exact bounded contract reply or close without an SSH open. 5. No authentication or parser path allocates from an input length without a fixed cap, blocks a lifecycle or SSH executor, creates a side queue, retains payload after close, or leaves a pending slot or descriptor behind. 6. Deterministic shared tests and explicit iOS and macOS provider-sandbox validation rows cover slow trickle through greeting and RFC 1929 fields, wrong credentials, a client that stalls both method and authentication replies, cancellation at each authentication phase, stale-generation handoff, pending-capacity recovery, and descriptor cleanup; the evidence distinguishes executable rows from compile/link rows for each platform.
