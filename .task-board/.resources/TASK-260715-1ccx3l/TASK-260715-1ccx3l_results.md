# TASK-260715-1ccx3l — Relay target-shell results

## Outcome

The repository now contains a buildable, standard-library-only Go module pinned
to Go 1.26.5. It produces `relux-relay` and
`relux-relay-protocol-test` for Darwin/Linux amd64/arm64 with
`CGO_ENABLED=0`, `-trimpath`, disabled VCS auto-embedding, and an empty build
ID. No UDP socket, association, remote-installation, SSH-exec, or publication
behavior was added.

Both binary families expose deterministic `smoke` JSON containing executable
version, protocol version, source revision, and build target. The relay reports
`relayBehaviorImplemented: false`. The protocol-test `run` entry point executes
only an empty-health validation and one schema-backed version-mismatch rejection.

## Manifest, checksum, license, and SBOM hooks

The default Apple bundle input is `.build/relay/apple-bundle-input`. It contains
exactly:

- four canonical relay executables;
- four SPDX 2.3 JSON SBOMs generated by Syft 1.48.0;
- `relux-relay-manifest-v1.json`;
- sorted `relux-relay-SHA256SUMS` entries for binaries, SBOMs, manifest, and notice;
- `THIRD_PARTY_NOTICES/Go-BSD-3-Clause.txt` with the repository MIT license and
  checksum-verified Go 1.26.5 BSD-3-Clause license.

`relay/manifest-v1.schema.json` and the verifier reject missing/unknown fields,
wrong toolchain/protocol versions, noncanonical target identity, duplicate or
missing targets, invalid sizes/hashes, host/unsafe paths, additional files,
unreviewed SBOM dependencies, incorrect standard-library provenance/license,
wrong binary architecture/build metadata, and checksum drift. Release mode also
rejects a dirty checkout or source revision different from `HEAD`.

Each SBOM contained only the relay module, its binary package, and
`stdlib@go1.26.5` declared `BSD-3-Clause`; the hooks therefore execute with the
empty third-party dependency set.

## Privacy and anomaly record

The generated smoke output, manifest, checksums, SBOMs, notices, and this outcome
contain no raw spawn log, host identifier, absolute local path, credential,
payload, or reflected remote-controlled string. The automatically attached raw
spawn-log resource was removed from the versionable task outcomes.

The first aggregate Make validation exposed inherited workstation `GOROOT` and
cache state mixing Go 1.25.5 objects with the Go 1.26.5 driver. Direct test/vet
commands now pin the exact `GOROOT`, disable `GOENV`, and use isolated ignored
Go cache/module paths; the full validation passed after this correction.
