# BUG-260728-2j25tu: stabilize-udp-adapter-cancellation-snapshot-race

## Description
Two tests in HEVUDPDatagramAdapterTests fail intermittently on the same assertion shape: snapshot.activeConnections is observed as 1 where 0 is expected. Observed three times in roughly twenty-four full swift test runs on 2026-07-28 during TASK-260715-ypo7yo r12 gating, on an unmodified tree: git status --porcelain over Sources, Tests, Package.swift, Protocol, relay, scripts and .spec was empty for the whole session, and r12 changed board resources only. Instances: HEVUDPDatagramAdapterTests.swift:646 "stale generation loss and cancellation cannot close current admitted or pending owners" (twice) and HEVUDPDatagramAdapterTests.swift:333 "relay errors, close, expiry, session loss, and stale callbacks close only their owner" (once). Both read await adapter.snapshot() immediately after a peer-observable event - receiveEOF returning on the affected peers - while the adapter decrements activeConnections in its own task. A peer seeing EOF does not imply the adapter has finished its teardown bookkeeping, so the assertion races adapter-internal state against a peer-observable event. This is a shared pattern in the suite, not one assertion.

## Scope
In scope: remove the race for every assertion in HEVUDPDatagramAdapterTests that reads adapter-internal state immediately after a peer-observable event - either by having the adapter publish teardown completion the test can await, or by making snapshot() observe a settled state - and audit the sibling assertions in the same blocks (registry.associationCount, metrics.lateCallbacks, metrics.cancellations) for the same shape. Out of scope: changing the adapter cancellation semantics, the generation model, or any test outside this suite.

## Acceptance Criteria
1. Both named tests pass in at least twenty consecutive full swift test runs. 2. The fix removes the race rather than adding a sleep, retry, or eventually-style poll with a wall-clock bound. 3. Every assertion in this suite that reads adapter-internal state after a peer-observable event is either shown not to race or made deterministic the same way. 4. A TASK-ID-scoped outcome records the reproduction attempts, the observed failure rate before the fix, and the run count behind the after-claim.
