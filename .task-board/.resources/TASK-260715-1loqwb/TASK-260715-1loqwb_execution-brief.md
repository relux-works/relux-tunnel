# Execution brief — HEV-to-relay UDP datagram adapter

- Implement only the private client-side adapter between the accepted HEV `socks5.udp = tcp` byte stream, `ClientUDPAssociationRegistry`, and generated relay-v1 `UDP_DATAGRAM` / `UDP_ERROR` / close messages. Do not add the outer SSH frame pump, relay socket behavior, DNS policy, public SOCKS listener, or new resource-policy constants.
- Treat the accepted HEV inner record and relay-v1 schema/codecs as authoritative. Preserve IPv4, IPv6, opaque domain bytes, ports, payload bytes, association identity, and relay-observed response source endpoints exactly; do not resolve, normalize, log, or persist destinations.
- The incremental stream parser must handle every split/coalescing boundary with fixed ceilings before retention/allocation. Malformed length/address/port/oversize input must not allocate an association or leak bytes into another association.
- Bind one owned process-local HEV logical association to one generation-scoped registry handle. Enforce admission provenance so arbitrary callers cannot turn the adapter into a user-visible proxy. Close, expiry, UDP error, session loss, cancellation, and late callbacks must retire resources exactly once and must not revive reused IDs.
- Backpressure must remain explicit and bounded: no detached unbounded tasks, hidden side queues, busy-spin, retry-by-copy, or destination-bearing diagnostics. Reuse existing registry limits and typed outcomes rather than inventing final policy values.
- Add deterministic fake-HEV/fake-relay tests for both families, domains, split/coalesced input, multiple associations, bidirectional datagrams, partial/stalled I/O, external-admission rejection, error/close/session loss/cancellation, stale callbacks, exact bytes, and resource baselines. Prefer barriers/fake clocks over sleeps.
- Run the focused tests repeatedly, the relevant Swift race/concurrency checks available in the repository, the full Swift suite/build, relay protocol drift/vector gates, strict formatting, privacy/prohibition scans, and `task-board validate`. Attach task-scoped outcome evidence and hand off at `to-review`; do not call producer work done.
