# Run the physical M4 product, security, privacy, and accessibility matrix

## Description
Execute the final M4 user-journey matrix on one named Apple-silicon Mac, with the named physical iPhone deferred with iOS under ADR-024, after all feature and test tasks are review-ready. Validate the real Network Extension permission/session, system indicator, user-controlled SSH host, full/degraded/reasserting/failure explanations, diagnostics, privacy, migration, and accessibility.

## Scope
In scope: device/OS/Xcode/source/dependency revisions, approved test host/keys, fresh and returning users, profile/key import or generation, first trust, repeat trust, changed key, auth/passphrase errors, privacy acknowledgement, VPN permission/system approval, connect, full/degraded/reasserting/failure, QUIC/route settings display, app suspend/terminate/relaunch, disconnect, diagnostics/export/delete, legacy branch on Mac, locale/pseudo rows feasible on device, VoiceOver, keyboard, text scaling, screenshots/video, counters, redaction, cleanup, and pass/fail. Out of scope: production credentials/traffic, release signing/TestFlight/App Store, M1-M3 throughput/leak matrices except referenced evidence, regional licensing, and unsupported devices.

## Acceptance Criteria
1. On the named Apple-silicon Mac, with the iPhone row deferred with iOS under ADR-024, a user can configure, trust, acknowledge privacy, grant permission, connect, understand authoritative full/degraded/reasserting/failure state, inspect/export/delete diagnostics, and disconnect with system VPN status matching the provider. 2. Changed host key stops before auth; credentials remain in the approved Keychain boundary; app termination does not stop an active provider; diagnostics/export contain no prohibited markers. 3. Mac legacy behavior matches the approved coexist/migrate/retire decision with idempotency/rollback evidence and the preserved legacy build/release contract referenced. 4. VoiceOver plus keyboard complete the Mac journey, and the VoiceOver iPhone journey is recorded as deferred, at supported text scaling/contrast/motion settings with no critical accessibility blocker. 5. A TASK-ID-scoped redacted evidence bundle records matrix rows, environments, opaque fixture IDs, screenshots, system/capability state, export manifest/hash/categories, accessibility observations, cleanup, linked M1-M3 evidence, and explicit pass/fail.
